# WebStudio

A responsive business landing page developed as part of the GoIT Full-Stack Developer course.

## About the Project

WebStudio is a landing page for a digital agency. The project demonstrates the fundamentals of semantic HTML markup and CSS styling, with a focus on Flexbox layouts and proper content structure.

## Features

- Semantic HTML5 structure
- Flexbox layout
- Navigation and contact information
- Business advantages section
- Team members section
- Portfolio gallery
- Responsive image handling
- Custom typography using Google Fonts

## Technologies

- HTML5
- CSS3
- Flexbox
- Google Fonts
- Modern Normalize
